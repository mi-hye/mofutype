# MofuType Kawaii Zine UI 리프레시 설계

## 목표

현재 구현된 그룹 생성·참여·관계 그래프 기능을 유지하면서 첫인상을 더 키치하고 기억에 남는 일본 Gen-Z 취향의 `Kawaii Zine` 스타일로 바꾼다. 기능, 라우트, Supabase 계약, 입력 데이터, 접근성 계약은 변경하지 않는다.

## 비주얼 원칙

- 바탕은 따뜻한 크림색을 유지한다.
- 핵심 포인트는 핫핑크, 코랄 레드, 민트, 버터 옐로, 라일락을 사용한다.
- 모든 핵심 컴포넌트는 진한 잉크색 외곽선과 단단한 오프셋 그림자를 사용한다.
- 완벽하게 정돈된 SaaS 카드보다 스티커, 테이프, 도트 패턴, 약간 회전된 라벨, 비정형 캐릭터 프레임을 사용한다.
- 긴 폼과 30명 그래프에서는 패턴을 줄이고 정보 가독성을 우선한다.
- 동물 이모지는 사용하지 않고 기존 `/animals/<id>.svg` 계약과 접근 가능한 텍스트 폴백을 유지한다.

## 랜딩 화면

- 상단 로고와 `GROUP EDITION` 배지는 잡지 제호처럼 구성한다.
- 헤드라인은 `みんなの関係、ぜんぶ丸見え。`처럼 짧고 강한 일본어 카피를 사용한다.
- 헤드라인 일부에 핫핑크 색상과 잉크색 텍스트 그림자를 적용한다.
- 배경에는 CSS 도트, 스트라이프 원, 테이프 조각을 제한적으로 배치한다.
- CTA는 코랄 바탕, 굵은 잉크 테두리, 잉크 오프셋 그림자의 두꺼운 버튼으로 만든다.
- `#かわいい`, `#ちょい毒` 같은 작은 스티커를 장식 요소로 사용한다.

## 입력 폼

- 그룹 생성 폼은 연한 핑크 또는 크림 카드 위에 배치하고 검은 외곽선과 핫핑크 그림자를 사용한다.
- 레이블은 굵고 간결하게 유지하며 입력 필드 자체는 흰색 배경으로 가독성을 확보한다.
- `input[type="date"]`와 `input[type="time"]`은 브라우저 네이티브 컨트롤을 유지한다. 표시 언어는 사용자 브라우저·운영체제 로케일을 따른다.
- `わからない`은 작은 체크박스가 아니라 선택 가능한 스티커형 토글로 표현하되 실제 checkbox 의미와 키보드 접근성을 유지한다.
- 검증 오류는 현재의 `aria-invalid`, 설명 연결, 라이브 안내를 유지하며 시각적으로는 빨간 테이프 라벨처럼 보이게 한다.

## 그룹 그래프

- 그래프 배경은 도트 그리드가 들어간 밝은 크림색 캔버스로 만든다.
- 동물 노드는 원형 SaaS 아바타보다 비정형 스티커 실루엣과 굵은 외곽선으로 표현한다.
- 선택된 노드는 잉크 외곽선, 핫핑크 오프셋, 작은 `SELECTED` 스티커로 강조한다.
- 관계선은 기본 상태에서 얇고 낮은 불투명도를 유지한다. 선택 관계는 핫핑크 또는 민트로 강조하고, 해제된 관계는 버터 옐로·굵은 점선·`解放済み` 표시를 사용한다.
- 16~30명 밀집 상태에서는 장식보다 노드·관계선 식별을 우선한다.
- 캔버스는 보조기술에서 숨기고 기존의 안전한 관계 목록을 접근성 경로로 유지한다.

## 공통 컴포넌트

- Button: 코랄 primary, 민트 secondary, 흰색 ghost. 모두 굵은 테두리와 눌림 모션을 사용한다.
- Card: cream, pink, mint, violet 변형을 제공한다.
- StatusBanner: 상태별 색상뿐 아니라 아이콘 없는 텍스트 라벨·테두리 패턴으로 구분한다.
- 섹션 제목은 작은 회전 라벨과 굵은 헤드라인을 조합한다.
- 컴포넌트 스타일은 하드코딩하지 않고 CSS 디자인 토큰과 재사용 클래스에 집중한다.

## 모션과 접근성

- 버튼 hover는 그림자가 줄어들며 2~3px 눌리는 정도로 제한한다.
- 카드·스티커는 첫 진입 시 짧은 이동·회전 모션을 사용할 수 있다.
- `prefers-reduced-motion`에서는 모든 장식 모션과 부드러운 스크롤을 제거한다.
- 모든 텍스트와 컴포넌트 경계는 WCAG 비텍스트 대비 3:1, 일반 텍스트 대비 4.5:1 이상을 유지한다.
- 320px 너비에서도 가로 스크롤이나 잘린 폼 필드가 없어야 한다.

## 구현 범위

- `globals.css`의 디자인 토큰과 공통 장식 유틸리티를 갱신한다.
- 랜딩 페이지, 생성·참여 폼, 공통 Button/Card/StatusBanner, AnimalAvatar, GroupGraph/GroupScreen의 스타일을 갱신한다.
- DOM 의미, ARIA, 키보드 흐름, 테스트 가능한 상태 속성은 유지한다.
- 관계 상세·결제 기능은 이 리프레시와 별도 Task 9에서 구현한다.
- 실제 동물 SVG가 아직 없으면 기존 텍스트 폴백을 사용하고, 별도 컨텍스트가 제공한 자산을 나중에 그대로 연결한다.

## 검증 기준

- 기존 테스트·타입 검사·린트·프로덕션 빌드가 모두 통과한다.
- 랜딩, 생성 폼, 참여 폼, 2명 그래프, 16명 그래프, 30명 그래프를 모바일 viewport에서 시각 확인한다.
- 콘솔 오류, 텍스트 잘림, 44px 미만 핵심 터치 대상, 접근성 이름 손실이 없어야 한다.
- 프로덕션 소스에 동물 이모지나 SVG HTML 직접 주입이 없어야 한다.
